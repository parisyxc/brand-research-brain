# Contributing

Useful contributions improve source handling, portable installation, evidence attribution, or recovery from interrupted writes.

Create a temporary Brain, reproduce the behavior with a small nonprivate fixture, and describe the observed result. Keep runtime dependencies in the Python standard library. Development YAML validation uses the declared PyYAML dependency.

Run the unit tests, package validator and example replay from README before submitting a change. Check both manifests when changing version or metadata. Keep Chinese and English entry docs consistent.

For skill changes, test a realistic request from raw input in a fresh Brain. Evaluate source scope and reasoning, not exact prose. Do not provide an expected answer to the evaluating agent. Record whether a test used live retrieval, a supplied clip, a frozen summary, or a helper-only replay.

Do not contribute credentials, personal research folders, private supplier data, or third-party full articles. A minimal attributed summary is usually enough to reproduce a problem.
