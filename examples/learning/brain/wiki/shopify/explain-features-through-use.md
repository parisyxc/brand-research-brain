# 产品页：先讲使用场景，再讲功能

当产品功能不容易被理解时，先用一个具体场景解释用途，再展示机制与必要规格。

LiberNovo 的 Omni 页把随动支撑拆到头枕、靠背、座垫和扶手，并放入工作、创作、游戏情境。这是页面表达观察，不是提高转化的实验证据。

**用于自己的 Shopify：**写一张“场景 → 功能 → 可见变化”的小卡片，再把它变成产品页一个区块。若说不清用户何时需要这个功能，先回到选品洞察；不把营销演示当作性能测试。
