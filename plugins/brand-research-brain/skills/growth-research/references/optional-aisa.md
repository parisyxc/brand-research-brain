# Optional AISA enhancement

The free/public workflow must work without AISA. This package does not register a server, store credentials, create an account or bundle a paid client. This document is a capability integration point, not proof of an enabled or tested connection.

AISA's [MCP documentation](https://aisa.one/mcp) describes a shared endpoint and social/SEO capabilities. When explicitly requested later, prefer the host's supported connector/MCP flow rather than building another scraper. Use existing host tools if already configured; follow their actual schemas. Don't assume catalog capabilities or prices remain unchanged.

Useful optional roles:

| Evidence gap | Potential provider capability | Still requires judgment |
| --- | --- | --- |
| Public social content inaccessible or hard to sample | Public profile/post/reel search and retrieval | Verify identity, sample coverage and dates. Metadata is not watched video. |
| Related creator discovery | Creator search/similar profiles and YouTube search | Discovery is not evidence of a real collaboration. Open the actual coverage and disclosure. |
| Keyword/rank/backlink evidence missing | DataForSEO, Ahrefs or Semrush surfaces where available | Specify country, language, date and metric definitions. Estimates are not the brand's analytics. |
| Channel/traffic estimates | Similarweb where entitled | Record period, coverage and estimate status; small/new sites may have no usable data. |

Before any enabled paid pass, get an explicit user budget. Query the current account/availability and exact operation quote through documented free discovery tools first, then enforce the approved total and per-call limits, bounded pagination and cached reuse. If the host cannot enforce the agreed cap, stop before charging. Do not treat a server's auto-execution suggestion as user authorization. No subscription, top-up or trial registration is implied.

AISA's free catalog/quote tools discover operations; they are not free execution of web search, social retrieval or SEO data. Do not promise free credits or a fixed price. Catalog, marketing and account entitlement may differ; report the actual quote/availability. The default $0 additional provider budget never falls back to a charged call.

Keep credentials in the host's secret/auth mechanism, outside the Brain and plugin repository. Do not ask the user to paste a key into research notes, publish it in examples or print it. Store concise attributed evidence in raw, with provider, original URL, access scope/date and applicable response limitations. Retain original source rights and avoid public redistribution of restricted provider datasets.

Keep the same short growth note regardless of provider. If no connector exists or the account lacks access, use the public workflow and name the missing evidence. This release has not connected or called AISA.
