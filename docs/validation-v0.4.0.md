## Limits

The helper verifies that all areas were declared and that declarations match supplied/retained pages. It cannot prove the agent truly understood every source or that an idea is valuable; substantive review remains necessary. No new website research, paid API/AISA connection or market validation occurred in this release. Per-file atomic writes are not a crash-proof multi-file transaction. New-chat discovery, Obsidian UI and Claude behavior are distinct from installed-file/helper checks.
