### Content review

- Ruggable separates the category's maintenance tradeoffs, growth evidence/causality limits, and a transferable replaceable-layer hypothesis. Reported business figures remain estimates rather than verified revenue. The owner's note is distinct from the article.
- BenShot separates recipient-specific gift selection, site navigation/trust mechanisms, and a testable design principle. Homepage claims and selected reviews are not treated as independent performance, representative demand or retention evidence.
- Kaleidos has an unavailable article body and an unattributed surviving sentence. It produces one short growth research note with a falsifiable explanation task; it does not establish that Kaleidos actually executed the mechanism or grew from it. Category is skipped because the clip lacks a user job or category tradeoff; ideas is skipped because it would repeat the growth note without product evidence. Both reasons remain visible in the brand page, log and registry. Extracted claims are empty.

## Automated checks

**32 helper tests** cover the previous preservation, deduplication, locking and path checks plus required dimension coverage, write/review agreement, directory classification, missing retained pages, source citations, brand backlinks, four-page updates, unchanged related-page retention and review-only revisions. Both skills pass Skill Creator's quick validator.

The v0.1.0 example Brains also remain readable with the new checker; existing snapshots are not rewritten.

The release source ZIP and plugin ZIP are integrity-checked. The extracted source tree's tests, validation and public replay are run separately; the extracted plugin's initializer, multi-page intake/revision and checker are smoke-tested without relying on source-tree helper imports.

## Scope and limits

This is isolated agent forward testing plus deterministic helper/package testing, not an installed-host UI/discovery test or a multi-reviewer study. No plugin account installation, GitHub publication or public-directory submission has been performed. Live retrieval covered one homepage; all browser variants and access barriers are not exhaustively tested. Hosted GitHub Actions will run only after publishing.

The helper enforces explicit review records and file/citation relationships, not the truth or usefulness of an argument. Exact source-record fingerprinting is not semantic deduplication. Individual atomic file writes and a lock are not a crash-proof multi-file transaction. A source with insufficient evidence can still be researched as a clearly labeled hypothesis, as the Kaleidos note illustrates.
