# 按需研究社交、创作者与 SEO

默认学习仍然是读懂生意、三个具体做法和一个自己的小行动。需要知道品牌如何被发现时，再调用 `growth-research`。

> 深入研究这个品牌的社交媒体、创作者与 SEO。使用公开免费来源，写成简洁的增长学习，并链接回已有案例。

研究会主动离开官网：确认账号和当前产品，读取代表性帖子，找实际介绍/评测及合作披露，查看内容与搜索入口。结果是一篇稳定的 `wiki/growth/<品牌>-growth.md`，包含发现路径、三方向的证据与缺口、最多三个可借用做法。一个方向没有可靠材料时保留未知，不能以通用策略代替调查结果。

[UseIt 示例](../examples/growth/brain/wiki/growth/useit-growth.md) 展示了免费流程：网页读取器访问 X 返回403，但普通浏览器成功读到公开预览；Product Hunt 有Maker介绍、问答和试用积分；第三方目录/文章提供搜索介绍入口。没有登录、注册、付费 API 或创作者联系。

独立验证采用不同取样，只有 X 镜像可读，因而没有把账号当成已确认的官方资料。两份输出的差别说明访问环境会影响证据覆盖；没有资料就不能断言不存在，也不能自动开启付费查询。

“免费”指不新增数据提供商费用；研究仍使用现有Agent、浏览器与搜索服务。社交元数据不等于观看视频，hunter或优惠码不等于付费合作，页面收录不等于品牌主动做SEO，曝光也不等于订单。

AISA 仅预留为[可选增强](../plugins/brand-research-brain/skills/growth-research/references/optional-aisa.md)。本版本没有连接服务、保存 key 或调用付费数据。以后确有证据缺口时，才在用户明确请求并设定预算后，用宿主连接补充数据；免费流程不会因此失效。
